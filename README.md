# 📊 Análise de Vendas Globais com Power BI

## 🎯 Sobre o projeto

Projeto desenvolvido no Power BI Desktop com o objetivo de analisar dados de vendas globais por meio de indicadores e visualizações interativas.

O dashboard permite explorar o desempenho das vendas considerando diferentes categorias, países, segmentos, períodos e prioridades de entrega.

## 🛠️ Ferramenta utilizada

- Power BI Desktop

## 📈 Indicadores e análises

O dashboard apresenta:

- Total de vendas;
- Total de vendas por categoria;
- Vendas realizadas por país;
- Vendas por país considerando a prioridade de entrega;
- Média de vendas por país;
- Média de desconto por subcategoria;
- Análise das vendas por categoria;
- Análise por segmento;
- Análise por período.

## 📊 Visualizações

Foram utilizadas diferentes visualizações para facilitar a interpretação dos dados:

- Gráfico de barras para análise por subcategoria;
- Mapa para análise da média de vendas por país;
- Gráfico de barras empilhadas para vendas por país e prioridade de entrega;
- Cartão para apresentação do total de vendas;
- Gráfico de pizza para distribuição das vendas por categoria.

## 🎛️ Interatividade

O relatório possui filtros que permitem explorar os dados de acordo com diferentes perspectivas:

- **Segmento:** Consumidor, Corporativo e Home Office;
- **Ano;**
- **País.**

## 🔎 Principais informações

O dashboard apresenta um total de vendas de **12,64 milhões** e permite analisar a distribuição das vendas entre as categorias de **Suprimentos, Tecnologia e Móveis**.

Também é possível comparar as vendas entre diferentes países e observar sua distribuição de acordo com as prioridades de entrega.
